# 🚁 Aplicación de Gestión de Drones

Proyecto académico de **Ingeniería de Software II** orientado al desarrollo de una aplicación para la gestión de drones utilizados por una empresa.

El sistema tiene como entidad principal al **Dron** y contempla su relación con **Pilotos, Sensores y Misiones**. Su objetivo es centralizar y organizar la información de los drones y facilitar su administración.

## ⚙️ Funcionalidades principales

- Registro de drones.
- Consulta de drones.
- Actualización de información.
- Eliminación de drones.
- Gestión de las relaciones entre drones, pilotos, sensores y misiones.

## 🛠️ Tecnologías y herramientas

El proyecto se desarrolla aplicando conceptos de:

- **UML**
- **Programación Orientada a Objetos**
- **Diseño de Software**
- **Arquitectura de Software**
- **Git y GitHub**
- **JUnit**
- **SonarQube**

La implementación y documentación del proyecto se realizará progresivamente durante el desarrollo.
